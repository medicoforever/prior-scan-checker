# ⚡ Prior Scan Checker (Online App)

Instant prior imaging lookup for legacy PACS history. Enter a patient registration number (MRN) to see when a scan was done and what scan was performed.

[![Open in Streamlit](https://static.streamlit.io/badges/streamlit_badge_black_white.svg)](https://share.streamlit.io/deploy?repository=medicoforever/prior-scan-checker&branch=main&mainModule=app.py)

---

### Features
- **Ultra-Fast**: Sub-millisecond indexed queries over 2.12M historical reports.
- **Pure Clarity**: Shows **Date Done** and **Scan Type Done** with zero clutter (no doctor names, no timestamps, no extra tags).
- **Mobile Friendly**: Works smoothly on smartphones, tablets, laptops, and hospital workstations.
- **100% Free**: Deployable on Streamlit Community Cloud with 24/7 access.

---

### How to Deploy on Streamlit Cloud (Free & Instant)
1. Go to [share.streamlit.io](https://share.streamlit.io/) and log in with your GitHub account (`medicoforever`).
2. Click **"New app"**.
3. Choose:
   - **Repository:** `medicoforever/prior-scan-checker`
   - **Branch:** `main`
   - **Main file path:** `app.py`
4. Click **"Deploy!"**
5. You get a public/private link (e.g. `https://prior-scans.streamlit.app`) that you and all your friends can open on any phone or computer anytime!
